# Visible Tab Snapshot Copier

Chromeのツールバーから、現在表示中のタブの可視範囲をPNG画像として撮影し、クリップボードへコピーする拡張機能です。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. このフォルダを指定する

## 使い方

ツールバーの拡張機能ボタンを押し、「撮影してコピー」を押します。その後、対応するアプリや入力欄で貼り付けます。

この版はページ全体ではなく、現在画面に見えている範囲を撮影します。
