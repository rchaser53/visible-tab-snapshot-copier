# Visible Tab Snapshot Copier

Chromeのツールバーから、現在表示中のタブの可視範囲をPNG画像として撮影し、クリップボードへコピーする拡張機能です。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. このフォルダを指定する

## 使い方

ツールバーの拡張機能ボタンを押し、「撮影してコピー」を押します。その後、対応するアプリや入力欄で貼り付けます。

`Alt+Shift+S`（Macでは `Option+Shift+S`）でも撮影してクリップボードへコピーできます。ショートカットは `chrome://extensions/shortcuts` から変更できます。

ポップアップの「PNGとして保存」では、保存先をChromeのダウンロードフォルダからの相対パスで指定できます。初期値は `ChatGPT Snapshots` です。たとえば `work/screenshots` と指定すると、ダウンロードフォルダ内のそのフォルダへ保存します。

保存サイズの幅・高さをpxで指定すると、指定したサイズにリサイズしてPNGとして保存できます。片方だけ指定した場合は、初期状態では縦横比を維持してもう片方を自動計算します。両方を空欄にすると元のサイズで保存します。

この版はページ全体ではなく、現在画面に見えている範囲を撮影します。

コピーまたはPNG保存の処理が完了すると、開いているChatGPT（`https://chatgpt.com/`）のタブをアクティブにします。開いていない場合は新しいタブでChatGPTを開きます。
